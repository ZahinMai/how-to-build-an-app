# My Portfolio - Now Made a Template

A React, TypeScript, and Vite site for a professional portfolio. Online newsletter-theme, with hidden features, animations, and a blog section.

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local development URL when it starts. To check the production version:

```bash
npm run build
npm run check
npm run preview
```

`npm run check` runs the TypeScript compiler without emitting files. Use
`npm run format -- <paths>` to format specific files with oxfmt.

## Where to edit content

Most text and repeatable content lives in `src/data/portfolio.ts`:

- `PROJECTS` and `PROJECT_FILTERS`: portfolio project cards, detail modal
  content, and category filters.
- `SKILLS`: the technologies and methods listed in the profile section.
- `EXPERIENCE` and `ADDITIONAL_EXPERIENCE`: work history.
- `LEADERSHIP_AND_ACTIVITIES`: community involvement and leadership.
- `EDUCATION`: education entries.
- `POSTS`: personal journal entries, including their card cover image paths.
  Post copy and photo captions live in `src/data/blogStories.ts`.
- `CONTACT_LINKS`: LinkedIn, Instagram, email, and phone destinations and
  displayed labels.
- `NAV_LINKS`: main navigation labels and their section or page destinations.

Add vlog photos to `src/assets/blog/` using the filenames shown in the photo
placeholders. Update `POSTS` and `BLOG_STORIES` when adding or editing a post.

The contact section's **Download CV** link downloads the PDF at
`src/assets/cv-zahin.pdf`.

## Where to edit layout and styling

`src/App.tsx` chooses the current view and composes the main portfolio page.
Page sections are separate components under `src/components/`, including
`HeroSection`, `ProjectsSection`, `SkillsSection`, and `ContactSection`.

The personal journal and its post placeholder page live in
`src/pages/NotebookPage.tsx` and `src/pages/BlogPostPage.tsx`.

Global styles, responsive breakpoints, colors, typography, and journal-specific
styles live in `src/index.css`. Tailwind utility classes are also used directly
in component markup. `src/types/portfolio.ts` contains shared content types.

## Link map

The main navigation and matching destinations are kept together in
`NAV_LINKS` in `src/data/portfolio.ts`:

| Label | Destination |
| --- | --- |
| Home | Hero (`#work`) |
| Work | Projects (`#projects`) |
| Profile | Skills/profile section (`#profile`) |
| Side Quests | Personal journal (`#notebook`) |
| Writing | Writing section (`#writing`) |

The section IDs are set by the corresponding section components. If you rename
a navigation item or section, update both the `NAV_LINKS` destination and the
section's `id` so they stay in sync.

Journal post pages use hash routes in `src/App.tsx`: `#notebook` opens the
journal and `#post-0`, `#post-1`, etc. open the corresponding post in `POSTS`.
The gate and portfolio logo play the landscape transition before opening the
journal; direct links to `#notebook` work without the transition.

Contact and social destinations are centralized in `CONTACT_LINKS`. The
notebook's Instagram link and the portfolio footer reuse that data.

## Project structure

```text
src/
├── App.tsx
├── components/      # Reusable page sections and UI
├── data/            # Portfolio, journal, navigation, and contact content
├── hooks/           # Shared React behavior
├── pages/           # Notebook and journal post views
├── types/           # Shared TypeScript types
├── index.css        # Global theme and component styles
└── main.tsx         # React entry point
```

`dist/` is generated by `npm run build`; edit `src/`, not the generated files.
